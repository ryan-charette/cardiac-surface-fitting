# Outputs

Generated surfaces, benchmark CSVs, and profiler exports are written here by
examples and benchmark scripts. Most generated files are ignored.

The `final_4090/` bundle is intentionally kept because it captures the RTX 4090
benchmark run used by `docs/performance_report.md`, including CSV outputs,
environment details, Nsight Compute `.ncu-rep` profiler reports, and the
original downloaded `rtx4090_results_bundle.tar.gz` archive.
